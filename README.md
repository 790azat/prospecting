# EVNWEB prospecting

Ежедневный поиск потенциальных клиентов для EVNWEB.

Каждый день в 08:00 по Еревану (и по кнопке **Actions → daily-prospecting → Run workflow**):
1. `scripts/collect_osm.py` собирает отели, гостевые дома, рестораны, кафе, магазины, клиники, салоны, автосервисы и турагентства Армении из OpenStreetMap → `data/businesses.csv`.
2. `scripts/build_leads.py` проверяет их сайты скриптом `scripts/site_audit.py` (HTTPS, адаптация под телефон, старый ©, старые технологии, языки, бронь, мессенджеры, скорость) → `data/audit_cache.csv`.
3. В `data/leads.csv` попадают бизнесы без сайта (но с контактом) и с устаревшим сайтом (оценка 40+). Сверху отели/гостевые дома, потом рестораны/кафе, внутри по оценке.

Сообщения клиентам никто автоматически не отправляет.

Готовые пачки сообщений на каждый день лежат в папке проекта `prospecting/batches/`.

## Рассылка в Telegram

`scripts/tg_outreach.py` и `.github/workflows/telegram.yml` пишут первое сообщение бизнесам из `data/tg/queue.csv` с аккаунта Азата.
Лимиты: дни 1-3 по 10 сообщений, дни 4-7 по 15, дальше 20 (не больше 25). Пн-сб 10:30-18:30 по Еревану, паузы 4-10 минут, только текст.
При ограничении от Telegram рассылка встаёт на 3 дня. Отчёт за день приходит в «Избранное» в Telegram.
Секреты: `TG_API_ID`, `TG_API_HASH`, при облачном пароле `TG_2FA`. Сессия лежит зашифрованной в `data/tg/session.enc`.
Остановить: поставить `"stopped": true` в `data/tg/state.json`.

## Компании из LinkedIn

`data/linkedin/companies.csv` пополняет Claude: находит страницы компаний `linkedin.com/company/...` через поисковик
(в сам LinkedIn не заходит и его не парсит) и, если может, их сайт.
`scripts/linkedin_leads.py` (workflow **linkedin-leads**, запускается сам после изменения списка и по понедельникам):
ищет сайт перебором доменов по названию, проверяет сайты тем же аудитом и пишет лидов в `data/linkedin/leads.csv`
(«устаревший сайт», «нет сайта», «сайт не найден» — последнее проверить в поле Website на LinkedIn).
Маркетинговые агентства в лиды не попадают: это возможные партнёры.
Сообщения в LinkedIn Азат пишет сам, порядок в папке проекта `market/linkedin/metod.md`.
