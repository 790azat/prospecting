# EVNWEB prospecting

Ежедневный поиск потенциальных клиентов для EVNWEB.

Каждый день в 08:00 по Еревану (и по кнопке **Actions → daily-prospecting → Run workflow**):
1. `scripts/collect_osm.py` собирает отели, гостевые дома, рестораны, кафе, магазины, клиники, салоны, автосервисы и турагентства Армении из OpenStreetMap → `data/businesses.csv`.
2. `scripts/build_leads.py` проверяет их сайты скриптом `scripts/site_audit.py` (HTTPS, адаптация под телефон, старый ©, старые технологии, языки, бронь, мессенджеры, скорость) → `data/audit_cache.csv`.
3. В `data/leads.csv` попадают бизнесы без сайта (но с контактом) и с устаревшим сайтом (оценка 40+). Сверху отели/гостевые дома, потом рестораны/кафе, внутри по оценке.

Сообщения клиентам никто автоматически не отправляет.

Готовые пачки сообщений на каждый день лежат в папке проекта `prospecting/batches/`.
